# toolCell2isoCell

Sets cell names to "iso country code"."cell number"

## Usage

``` r
toolCell2isoCell(x, cells = "magpiecell")
```

## Arguments

- x:

  magpie object on cellular level

- cells:

  switch between magpie cells (59199) and lpj cells (67420)

## Value

return changed input data
