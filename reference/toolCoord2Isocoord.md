# toolCoord2Isocoord

Transforms an object with coordinate spatial data (on half-degree) to
object with 67420 cells and coordinate and iso country information

## Usage

``` r
toolCoord2Isocoord(x)
```

## Arguments

- x:

  magclass object to be transformed from coordinates to iso-coordinate

## Value

magpie object with 67420 cells in x.y.iso naming
